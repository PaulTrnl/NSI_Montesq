# Présentation SNT (Sciences Numériques et Technologie)



La **Sciences Numériques et Technologie** est un enseignement qui permet de découvrir les grandes notions du monde numérique qui nous entoure.

L'objectif est de comprendre comment fonctionnent les technologies que nous utilisons quotidiennement et de développer une culture numérique permettant de mieux appréhender les enjeux actuels.

---

## Objectifs de l'année

Au cours de l'année, nous allons apprendre à :

- comprendre le fonctionnement du Web et d'Internet ;
- manipuler et analyser des données ;
- découvrir les principes de la programmation ;
- comprendre le fonctionnement des objets connectés ;
- réfléchir aux enjeux du numérique dans la société ;
- développer un regard critique sur les usages du numérique.
