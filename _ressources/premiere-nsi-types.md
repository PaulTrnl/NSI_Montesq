# Les types de base en Python

Python propose plusieurs types de données de base :

- `int` : nombres entiers (ex : `5`, `-3`)
- `float` : nombres à virgule (ex : `3.14`)
- `str` : chaînes de caractères (ex : `"bonjour"`)
- `bool` : booléens (`True` ou `False`)

## Exemple

```python
age = 17
prenom = "Alice"
majeur = age >= 18
print(prenom, "a", age, "ans. Majeur :", majeur)
```
