# Le fonctionnement d'Internet

Internet est un réseau mondial d'ordinateurs qui communiquent entre eux grâce à des protocoles communs (notamment **TCP/IP**).

## Les notions clés

- **Adresse IP** : identifiant unique d'un appareil sur le réseau
- **DNS** : système qui traduit un nom de domaine (ex : `google.com`) en adresse IP
- **Paquets** : les données sont découpées en petits morceaux avant d'être envoyées
